# Kev 用什么数据训练（2026-09-29）

> 来源：Kev-4B model card（`third_party/kev/docs/model-cards/kev-4b.md`，`jaredpalmer/kev@3e1cd3b`）和 Kev README。以下均为 Kev 作者公布的数据，本项目未复现。
> 相关：[为什么选择 Kev](2026-09-29_WHY_KEV.md) · [专有数据收集与微调计划](2026-09-29_PROPRIETARY_DATA_AND_FINETUNE_PLAN.md)

## 模型结构

- **基座：** `Qwen/Qwen3.5-4B-Base`（Kev-0.8B / 9B 同一套配方；Kev-27B 从 Qwen3.8-27B 的后训练版本出发）。
- **适配：** LoRA r=16、α=32（约 3,380 万可训练参数），外加一个从头训练的 pointer head，输出每个选项的概率分布。
- **校准：** checkpoint 内置一个在分布内 dev 集上拟合的温度，服务时默认使用。
- **没有使用任何 Jev 的输出做训练。**

## 训练数据

| 阶段 | 数据 | 说明 |
|---|---|---|
| 主训练 `decision-v7` | 10 个公开数据集 × 1,000 条 | 路由、意图分类、蕴含、科学问答等，例如 banking77 |
| | 896 条策略最小对（policy minimal pairs） | 九个模板族 |
| | 1,680 条随机规则结构样本 | 60 个随机生成的规则结构，四种渲染风格 |
| 增量：日期与证据缺失 | 1,425 条生成样本 | 带日期的策略案例；删掉关键句、目标为均匀分布的"证据不足"案例 |
| 增量：`hard-v1` | 6,000 条 | 程序生成、标签由求解器计算：长策略文档与例外、优先级取舍、概率与期望值、多跳、日期与算术、判断给定答案、证据缺失时弃权 |
| 增量：`devtools-v1` | 5,320 条 | CodeReviewer、CommitPackFT、FlakeFlagger、Aegis |
| 增量：真实文档 | 5,219 条 CFPB 消费者投诉 | 两个开源教师模型与消费者自填类别一致才保留标签 |

- 训练时 state 最长 384 token。
- 增量训练都混入了 `decision-v7` 回放数据，防止遗忘。

## 对本项目意味着什么

- **Kev 没有在 agent 安全数据上训练过**：没有 tool 调用轨迹、提示注入、目标偏离、收款人核对这类样本。所以它在本项目的 rubric 问题上开箱表现一般（见 [为什么选择 Kev](2026-09-29_WHY_KEV.md) 的已知局限）。
- **Kev 自己的经验说明领域微调有效，但增益在分布内。**
  - 一个示例客服任务：1,050 条生成数据，Kev-4B 从 67.7% 到 73.6%；只用 400 条时，增益落在噪声里。
  - CFPB 真实投诉：5,219 条，Kev-4B 从 0.804 到 0.904。
  - `hard-v1` 在分布内 +26.3 个点，但在分布外的 JevBench hard 档只有 +9.0 个点，约为三分之一。
